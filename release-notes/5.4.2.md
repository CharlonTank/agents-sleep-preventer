# Agents Sleep Preventer 5.4.2

## Fixed

- **Quitting from AppleScript, launchers and scripts works.** `quit app "AgentsSleepPreventer"` (and the Quit command of tools like Raycast or Alfred) reached the app's background agent, which refused it with error -1708, so the app kept running. The request now closes the whole app, as the menu's Quit does.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.4.2.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.4.2-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
