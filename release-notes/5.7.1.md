# Agent Session Pilot 5.7.1

## Fixed

- **The Telegram listener no longer keeps 1.2 GB after a voice note.** The listener that reads Telegram for every session transcribed voice notes in its own process. The model's memory stayed taken afterwards, for days, until macOS raised a memory pressure alert. Each voice note is now transcribed in a short-lived process, which gives the memory back as soon as it is done. Transcription speed and quality are unchanged.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.7.1.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.7.1-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.7.1-linux-x86_64.tar.gz`. Check it against the SHA-256 shown here and on https://asp.charlon.dev/#install, or use https://asp.charlon.dev/install.sh, which checks it for you (read it first).
