# Agents Sleep Preventer 5.0.2

## New: Sleep when done

- A fourth sleep mode in the popover: **Force sleep · Sleep when done · Auto · Force awake**.
- Sleep when done keeps the Mac awake while your agents work, then puts it to sleep once they have all finished, even on power where macOS may never sleep on its own.
- It waits 30 seconds after the last agent finishes, and until the Mac has had no keyboard or mouse input for a minute, so it never sleeps while you are using it.
- It switches back to Auto just before sleeping, so waking the Mac never sends it straight back to sleep. Also available as `asp force when-done`.

## Fixes

- **A docked MacBook no longer goes to sleep while you use it** (#6). When the last agent finished, a MacBook in clamshell mode with an external display was treated as "lid closed, nobody here" and put to sleep mid-typing. Sleep is now only forced when the lid is closed, no external display is active and there was no input for a minute.
- The dictation shortcut diagnostic no longer writes to the log every 15 seconds.

## Security

- The passwordless sudo rule installed for `pmset` now only allows the four exact commands the app runs, instead of any `pmset` command, and is checked with `visudo` before being kept. It applies to new installs and when you reinstall the agent hooks (••• → Reinstall Agent Hooks). Thanks to @lbdremy (#5).
- Installs running as root now resolve the logged-in user, so hook files are no longer left owned by root.
