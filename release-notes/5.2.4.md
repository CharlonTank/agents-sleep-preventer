# Agents Sleep Preventer 5.2.4

- **The new icon now fills its space on macOS 26 and later.** It was shown small, inside a gray square, in Finder and the Dock. It now uses the system's own icon shape, at the same size as other apps.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.2.4.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.2.4-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
