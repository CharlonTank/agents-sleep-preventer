# Agents Sleep Preventer 4.3.0

## Sleep control

- **Sleep override control in the popover**: Force sleep · Auto · Force awake. Force awake keeps the Mac awake with no agent running; Force sleep lets it sleep even while agents work. New `asp force awake|sleep|auto` CLI.
- **Background subagents are now detected.** Multi-agent orchestration (Claude Code workflows/ultracode, Codex /ultra) keeps working after the turn's Stop hook fires: ASP keeps the session marked working while its process tree is still busy, and new Claude Code hook events (SubagentStart, SubagentStop, PostToolUse) refresh it. "Task finished" notifications now fire when the background work actually ends.
- Hook install now **merges** into `~/.claude/settings.json` and preserves your own hooks; uninstall removes only ASP's entries.

## Dictation

- **Record any keyboard shortcut** for dictation (Settings → Record…): modifiers + any key, or modifier-only combos. The trigger key is swallowed so it never leaks into the focused app.
- **Near-instant transcription on release**: long dictations are committed in chunks at natural pauses while you speak; releasing the hotkey only transcribes the last few seconds.
- Live preview now shows the full transcript and stays fast on minute-long dictations.

## Permissions

- New **Permissions panel** (also in the ••• menu): shows Accessibility and Microphone status, deep-links to the right System Settings pane, refreshes live and restarts dictation as soon as access is granted.

## Fixes

- Toggling prevention off no longer force-sleeps a docked (clamshell) Mac.
- Thermal protection no longer erases your override; it suspends it and restores it when the Mac cools down.
- Settings are written atomically; concurrent readers can no longer observe a half-written file.
