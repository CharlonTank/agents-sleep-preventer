# Agents Sleep Preventer 5.2.3

## New icon

- **A new look.** The app icon is now a glowing crescent moon keeping a terminal prompt company through the night: your Mac keeps watch while your agents work. It stays readable down to the smallest sizes in Finder and the Dock. The website and README show it animated: twinkling stars, a breathing moon and a blinking cursor.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.2.3.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.2.3-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
