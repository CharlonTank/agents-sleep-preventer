# Agent Session Pilot 5.8.4

## Telegram

- **A session gets a topic even though Telegram no longer creates new ones in private.** Since 9 November 2026, Telegram refuses the bot new topics in its private chat (`BOT_TOPIC_WRONG_HOME`, tdlib/telegram-bot-api#944), while the topics it already created keep working. A session that needs one now takes over the topic of a session that was stopped or gone for more than a week, with no project group and no message waiting, the longest-gone first, and renames it.
- When no topic is free, the session's hello says Telegram refused it, instead of starting quietly without one.
