# Agent Session Pilot 5.8.1

## Fixed

- **A long session name no longer widens the menu.** With a session named "my-app · Fix the login redirect on Safari", the menu grew wider than its window and cut off its right edge (the status pill and the "Force awake" button). The name is now shortened with "…", and the full name shows when you hover over it.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.8.1.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.8.1-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.8.1-linux-x86_64.tar.gz`. Check it against the SHA-256 shown here and on https://asp.charlon.dev/#install, or use https://asp.charlon.dev/install.sh, which checks it for you (read it first).
