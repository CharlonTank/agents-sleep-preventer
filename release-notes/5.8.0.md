# Agent Session Pilot 5.8.0

## New

- **Every session by its name.** Two sessions in the same project used to share one row ("3 sessions"). Now each named session has its own row: "my-app · dev", "my-app · seo". The name is the one you gave with `/rename`, or the one Claude Code made up. Clicking a row still brings that session's terminal to the front.
- **Profiles and Claude accounts.** If you run Claude Code with several `CLAUDE_CONFIG_DIR` profiles:
  - each row says which profile the session runs under;
  - the menu's header shows the Claude account in use;
  - when your profiles use different accounts, a "Claude accounts" block lists each profile with its account and its number of sessions.
- **`asp sessions`** prints the same view in the terminal, grouped by project: each session's name, state, profile, branch and pid, plus each profile's account.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.8.0.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.8.0-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.8.0-linux-x86_64.tar.gz`. Check it against the SHA-256 shown here and on https://asp.charlon.dev/#install, or use https://asp.charlon.dev/install.sh, which checks it for you (read it first).
