# Agent Session Pilot 5.7.0

## New name

- **Agents Sleep Preventer is now Agent Session Pilot.** It still keeps your computer awake while agents work. It now also lets you drive your sessions from Telegram, watches their RAM and disk, opens them in one go, and runs on Linux servers. The acronym stays ASP and the command stays `asp`. Nothing changes for you: same app, same settings and permissions, and updates keep coming through the app as before.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.7.0.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.7.0-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.7.0-linux-x86_64.tar.gz`, or `curl -fsSL https://asp.charlon.dev/install.sh | sh`.
