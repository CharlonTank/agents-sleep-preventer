# Agent Session Pilot 5.8.8

## Telegram

- **No more stalled calls over IPv6.** From some networks, IPv6 connections to Telegram's API hang now and then while IPv4 always answers. asp now connects over IPv4 first, for the Bot API and for the relay, and falls back to IPv6 only when IPv4 fails. A machine without IPv4 still uses IPv6 directly.
- **A stalled call gives up sooner.** Opening a connection is capped at 10 seconds. Asking Telegram where a file is stored gives up after 20 seconds instead of 70, and a download that hasn't started after 20 seconds is retried instead of waiting up to 5 minutes. A hung call no longer holds up the messages behind it.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.8.8.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.8.8-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.8.8-linux-x86_64.tar.gz`. Check it against the SHA-256 shown here and on https://asp.charlon.dev/#install, or use https://asp.charlon.dev/install.sh, which checks it for you (read it first).
