# Agents Sleep Preventer 5.6.0

## New

- **Server mode on Linux.** For a machine that never turns off: `curl -fsSL https://asp.charlon.dev/install.sh | sh`, then `asp telegram setup`. You get the same Telegram control and RAM and disk watch as on macOS, and the workshop opens your sessions in tmux. A systemd user service keeps the watch running after you log out. Voice notes are transcribed on the server, with ffmpeg and the Parakeet model that setup offers to download.
- **Workshop in tmux, on macOS too.** `asp workshop` uses tmux inside tmux, over SSH or without iTerm (`terminal = "tmux"` in `[workshop]`), so a headless Mac mini can run your sessions as well.

## Fixed

- Piping a command into `head` (`asp status | head`) no longer prints a panic.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.6.0.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.6.0-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.6.0-linux-x86_64.tar.gz`, or `curl -fsSL https://asp.charlon.dev/install.sh | sh`.
