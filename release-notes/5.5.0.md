# Agents Sleep Preventer 5.5.0

## New

- **Talk to your Claude Code sessions from Telegram (macOS).** Connect your own bot once with `asp telegram setup` (a token from @BotFather, then one message from your Telegram account), then type `/telegram` in any Claude Code session: it listens to you on Telegram and answers there. One bot serves every session; each message finds its session through its topic, a leading `name:`, a reply, or buttons when it's ambiguous. Photos and files are downloaded. Voice notes are transcribed on your Mac by the Parakeet model you use for dictation, with nothing else to install. Project groups let a client talk to the session working for them.
- **RAM and disk watch (macOS), on by default.** ASP names the Claude Code session behind a drift: a process tree over 8 GB, memory pressure, swap, or a disk almost full or emptying fast. You get a notification. When Telegram is set up, the culprit session also gets the alert in its Telegram inbox, and you get a message when nobody is to blame or it's critical. It measures real memory (compressed memory included) and never kills anything. `asp monitor status` shows each session's RAM. Thresholds are in `config.toml` (`[monitor]`).
- **Workshop (macOS).** `asp workshop` opens your named Claude Code sessions in iTerm in one go, from `[workshop]` in `config.toml`: resumed by id, startup questions answered, and your first prompts typed.

## Fixed

- **The `asp` command in the terminal follows updates.** It was a copy made at install, so after Sparkle updates it stayed at an old version. It's now a link to the app, fixed automatically at the next launch.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.5.0.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.5.0-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
