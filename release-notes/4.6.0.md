# Agents Sleep Preventer 4.6.0

## Updates

- **Update badge in the popover**: when a background check finds a new version, a green download arrow appears next to the ••• menu with an "Update Ready!" tooltip. Click it to install — no window ever steals your focus on its own.
- **Check for Updates works on the first click.** As a menu bar app we are never frontmost, so Sparkle's window used to open behind everything and the click looked ignored.
- Background update checks now run hourly instead of daily.
