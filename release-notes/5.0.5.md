# Agents Sleep Preventer 5.0.5

## Agent detection

- **Agent-team teammates now keep the Mac awake.** Teammates opened in their own terminal pane run the agent's versioned binary directly, so they were not recognized: the Mac could sleep while they worked, and they were missing from the popover. They are now detected and listed with their project.
- **Background tasks keep the Mac awake after the turn ends.** A command still running in the background (a benchmark waiting on the network, a polling `sleep`) now counts as work even when it uses no CPU. The Mac stays awake until it finishes, then you get the usual "task finished" notification.

- Windows x64: `AgentsSleepPreventer-5.0.5-windows-x86_64.zip`. Windows behavior is unchanged; extract the full ZIP and launch `asp.exe`.
