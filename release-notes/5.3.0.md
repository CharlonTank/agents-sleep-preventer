# Agents Sleep Preventer 5.3.0

## New

- **Auto-resume after network drops (macOS).** On a train or a flaky Wi-Fi, Claude Code or Codex can stop mid-task on a network error and wait until you type "continue". Agents Sleep Preventer now does it for you: once the connection is back and stable, it types a "continue" prompt into that agent's terminal (iTerm2, Terminal or tmux). Meanwhile the menu shows the agent as cut off, and the Mac stays awake for up to 30 minutes.
  - API errors such as "overloaded" are retried after a pause.
  - Usage-limit, login and billing errors are left alone.
  - It waits while you are typing in that terminal, and gives up after 3 tries.
  - Turn it off from the **…** menu or with `asp auto-resume off`.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.3.0.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.3.0-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
