# Agents Sleep Preventer 5.2.5

## Fixes

- **Codex shows as working again, and keeps the Mac awake.** Since Codex 0.160, the CLI runs its turns in a shared background service, so ASP could no longer tell which Codex session was working: it showed every Codex as idle and let the Mac sleep. ASP now matches the service's activity to the right terminal session.
- **No more stray "Codex" rows from the ChatGPT app.** Its background services showed as idle Codex agents named "/" or "Resources".
