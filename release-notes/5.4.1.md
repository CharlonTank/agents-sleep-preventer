# Agents Sleep Preventer 5.4.1

## Faster

- **Your agents no longer wait on Agents Sleep Preventer.** Claude Code runs its hooks before and after every tool call and waits for them. On a busy Mac, ASP's hooks took 0.4 to 1.1 seconds each, because they ran `ps` and `pmset` every time. They now read the process list and the power state straight from macOS and take a few dozen milliseconds, as measured in Claude Code's own hook timings. The menu refreshes about seven times faster too.

## Fixed

- **Claude Desktop sessions are detected.** Claude Desktop runs its own copy of Claude Code from a folder whose path contains a space. Those sessions did not show in the menu and did not keep the Mac awake.
- A Bash command written on several lines now shows on one line in the menu.
- The shell that Claude Code starts before a session's first command no longer shows up as a running task.
- The thermal check reads macOS's own thermal and CPU-limit status, and only counts real throttling.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.4.1.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.4.1-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
