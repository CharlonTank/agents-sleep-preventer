# Agents Sleep Preventer 5.0.0

Agents Sleep Preventer now runs on Windows 10/11 x64 as well as macOS.

## Windows

- Native tray app and CLI with automatic sleep prevention, manual overrides, multi-agent tracking, and Claude Code/Codex hooks.
- Local dictation with bundled Whisper and Parakeet engines. Parakeet is the Windows default for fast CPU transcription. Download a model from the tray menu, then press Ctrl+Alt+Space to start and finish a recording.
- Dictation settings for model, language, shortcut, vocabulary, and recording sounds; visible recording/transcription status, Unicode text insertion, clipboard fallback, and local history.
- Per-user installation and start at login, with existing hooks and preferences preserved.
- Automatic AVX2 acceleration on compatible CPUs, with portable speech engines for older PCs.
- A complete portable ZIP: no separate speech engine or Visual C++ runtime installation required.

The Windows version respects Windows lid and power-button policies. macOS-specific Fn shortcuts, agent notifications, Sparkle, and automatic Hermes/WSL hook setup remain platform-specific. The Windows ZIP is unsigned.

## macOS

Existing sleep prevention, dictation, agent controls, and signed Sparkle updates are preserved. Shared hook configuration logic now serves both platforms.

## Downloads

- macOS: `AgentsSleepPreventer-5.0.0.dmg`
- Windows x64: `AgentsSleepPreventer-5.0.0-windows-x86_64.zip` — extract the full ZIP and launch `asp.exe`.
