# Agent Session Pilot 5.8.9

## Telegram

- **Codex sessions can listen on Telegram too.** Type `$telegram` (or `/telegram`) in Codex. The session registers and announces itself like a Claude Code session, and the owner's messages reach it in its own topic.
- Codex isn't woken when a background command ends, so it listens differently. When its turn ends, a Codex Stop hook (`asp telegram codex`) waits for the owner's messages and hands them to Codex as its next prompt. Waiting costs nothing, and Codex gets a short check-in once an hour.
- `asp telegram skill` now also installs the skill for Codex (`~/.codex/skills/telegram`) and adds the hook to `~/.codex/hooks.json`. Codex runs a new hook only after you approve it: type `/hooks` in Codex and trust `asp telegram codex`, once.
- While the hook waits, the Codex terminal stays busy. Press Esc to take the keyboard back, then ask Codex to stop Telegram.
