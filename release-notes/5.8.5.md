# Agent Session Pilot 5.8.5

## Telegram

- **Named topics in a project group.** `asp telegram send --topic "Gallery"` writes in the group's topic of that name, case and spaces ignored. The topic is created if it doesn't exist yet, and again if it was deleted. Messages received from a group with topics now say which topic they come from, for example `[group Alice's site, topic Gallery]`, and `group list` shows each group's topics. Topic names are learned when the bot creates a topic, when a member creates or renames one, and from the messages written in it.
- **Buttons under a message.** `asp telegram send --buttons "Yes|No"` puts up to 8 buttons under the message. A press by a member of the project group, or by the owner in private, comes back to the session like a message, and the buttons are replaced by the choice. Each message takes one answer.
- Both work like sync-telegram's `--sujet` and `--boutons`, which `asp telegram send` also accepts. The two tools share the same files, so either one can file the presses, whichever is reading Telegram.

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.8.5.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.8.5-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
- Linux x86_64 (server mode): `AgentsSleepPreventer-5.8.5-linux-x86_64.tar.gz`. Check it against the SHA-256 shown here and on https://asp.charlon.dev/#install, or use https://asp.charlon.dev/install.sh, which checks it for you (read it first).
