# Agents Sleep Preventer 5.2.1

## Fixes

- **Runs again on macOS 14 Sonoma, 15 Sequoia and 26 Tahoe.** Since 5.0.7 the menu bar app was accidentally built to require macOS 27, so it would not open on earlier versions, even after an automatic update. The app and its dictation engine now target macOS 14 and later, on every Apple Silicon Mac, and updates are no longer offered to Macs that can't run them.
- **The agents menu is no longer cut off on the right.** On some Macs the sleep control (Force sleep · Sleep when done · Auto · Force awake) was wider than the menu, hiding the status pill, the last option and the ••• button. The menu now widens to fit it. Thanks @infrachris for the report (#10).

## Downloads

- Windows x64: `AgentsSleepPreventer-5.2.1-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
