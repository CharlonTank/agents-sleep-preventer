# Agents Sleep Preventer 5.0.4

## Privacy and security

- **Dictated text is no longer written to the log.** Earlier versions logged every transcription to `~/Library/Logs/AgentsSleepPreventer/asp.log`, a file that is never rotated. Only the length is logged now, and transcripts already in the log are removed the first time 5.0.4 starts. Your dictation history (••• → Dictation History) is unchanged.
- **Agent state moved out of the shared `/tmp`.** The files hooks use to mark agents as working, waiting for you, or finished now live in your private temp folder, so another account on the same Mac cannot keep it awake or send fake agent notifications.
- Removed an old prebuilt binary and unused installer files from the repository.

These close the remaining points of the community security audit (#4).

## Downloads

- macOS: `AgentsSleepPreventer-5.0.4.dmg`, signed and notarized, with Sparkle updates.
- Windows x64: `AgentsSleepPreventer-5.0.4-windows-x86_64.zip`. Windows behavior is unchanged; extract the full ZIP and launch `asp.exe`.
