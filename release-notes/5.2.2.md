# Agents Sleep Preventer 5.2.2

## Fixes

- **The agents menu no longer freezes on "No agents running".** With many sessions or long background commands, the menu could stop refreshing for good, showing "No agents running" and READY while agents were working (the Mac was still kept awake correctly). It now always refreshes.

## Sleep when done

- **Any time limit.** Besides the presets, now up to 12 h, "Custom…" lets you type any duration, e.g. 17h, 20 hours, 1h30 or 45m, to let a long task run through the night and still have the Mac sleep afterwards. From the terminal: `asp force when-done --within 17h`.

## Downloads

- macOS 14+ on Apple Silicon: `AgentsSleepPreventer-5.2.2.dmg`, signed and notarized, with Sparkle updates, or `brew install --cask charlontank/tap/agents-sleep-preventer`.
- Windows x64: `AgentsSleepPreventer-5.2.2-windows-x86_64.zip`. Extract the full ZIP and launch `asp.exe`.
