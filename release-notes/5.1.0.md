# Agents Sleep Preventer 5.1.0

## Permissions

- **Dictation works when the app was opened from the disk image or Downloads.** From there macOS could show the Accessibility switch on while dictation still had no access, and "Move & Relaunch" left the old copy running with a red Accessibility status. The app now offers to move itself to Applications before anything else, then relaunches from there and quits the old copy.
- **One permissions window.** First launch no longer opens a second permissions window next to the ASP Permissions panel; it only offers to download the dictation model.
- **"Switch already on but still red? Reset it…"** in the permissions panel clears a grant macOS kept for another copy of the app and asks again.

## Agents menu

- **See why an agent needs you.** "Needs you" rows show the agent's own message, such as "Claude needs your permission to use Bash".
- **See and stop what each session runs.** A dev server or a polling loop left running in the background is listed under its session, with a Stop button that ends it and everything it started.
- **Other Claude Code profiles behave like the default one.** Sessions started with another config dir (`CLAUDE_CONFIG_DIR`, e.g. `~/.claude-evo`) now keep the Mac awake while they work, and no longer stay stuck on "Needs you" for hours once you're back.
- Chrome's Claude extension helper no longer shows up as an idle agent.
