# Agents Sleep Preventer 5.0.3

## Dictation

- **A changed dictation shortcut now works right away.** Picking a new shortcut (or a new model) in Settings used to have no effect until the app was relaunched. Changes now apply within a second of saving.

## Also in 5.0.2

- **Sleep when done**: a fourth sleep mode that keeps the Mac awake while agents work, then puts it to sleep once they have all finished and you have stepped away, and switches back to Auto just before sleeping.
- A docked MacBook (lid closed, external display) no longer goes to sleep while you use it when the last agent finishes (#6).
- The passwordless sudo rule for `pmset` is restricted to the exact commands the app runs.

## Downloads

- macOS: `AgentsSleepPreventer-5.0.3.dmg`, signed and notarized, with Sparkle updates.
- Windows x64: `AgentsSleepPreventer-5.0.3-windows-x86_64.zip`. Windows behavior is unchanged; extract the full ZIP and launch `asp.exe`.
