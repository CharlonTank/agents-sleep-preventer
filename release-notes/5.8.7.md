# Agent Session Pilot 5.8.7

## Telegram

- **Voice notes no longer get lost when Telegram is slow.** When a file doesn't download because Telegram's file server didn't answer in time, the listener now tries twice more before giving up.
- If it still fails, the session sees `[voice note not downloaded …] (to get it: asp telegram fetch --message N)`. That command downloads the file again, transcribes a voice note and prints the line, so the owner doesn't have to send it again.
- `asp telegram fetch` also recovers files that sync-telegram failed to download, even though it keeps no reference to them. The bot forwards the message to the owner without sound, deletes the copy right away, and downloads the file from the reference Telegram returns with the copy.
